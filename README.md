# One Letter for Your Day

Entry for [One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36) on make.fun.

Send exactly one letter, A to Z, standing for the word that describes your
day. This entry sends **Z** — for "zombie": a day with zero sleep, where you
walk around half-awake on autopilot until the night finally lets you
collapse. Vivid, funny, and true — and the letter fits twice over, since Z
is also the first letter of "zero sleep".

`main.py` (packed from `entry.py` with the kit's `makefun compress`) writes
the single letter to `/output/entry.txt`, deterministically.

Run it with `python3 main.py`; run it twice and the output is byte-identical.
